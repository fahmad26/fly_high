## Generation prompt

Use case: stylized-concept. Asset type: production mobile Roblox HUD button for Fly High, normal/unpressed state. Create ONE complete circular jump button on a genuinely transparent background, square 1024x1024 canvas. Straight-on orthographic 2D game UI illustration, no perspective tilt. Center a perfect round cyan/teal button occupying about 90% canvas width with even transparent padding. Include entire dark navy outer outline, restrained warm cream/gold thin inner rim, rounded turquoise raised face with soft cel-shaded depth and a subtle upper-left highlight. A single bold ivory upward arrow with short broad stem sits centered, clean dark navy edging, chunky readable silhouette at 64px. Friendly polished sky-adventure cartoon arcade style, crisp smooth edges, excellent contrast. Button is a cohesive finished illustration: the circle, rim, shading, arrow are all included. No text, no letters, no keyboard hint, no extra arrows or motion trails, no extra objects, no mockup, no collage, no background square, no heavy neon glow, no tiny diagonal textures, no realistic metallic material. Preserve transparent alpha outside the button and subtle close contact shadow only.
